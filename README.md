# Definitely Useless Buttons

A website made entirely of buttons that should not be pressed.

## How to run it
1. Keep `useless-buttons.html` and `beep-bope.mp3` in the SAME folder
2. Double-click `useless-buttons.html` (or host both files anywhere static)

## How to play
Press the button. Then figure out the rest yourself.

(Small hint: the R key forgives all sins.)
